# Principles

For the Project Manager and every role. Load only when the task needs it.

- Don't wait on the owner for work that can be undone; always wait for work that can't.
- Make every operation safe to repeat: a second run must not repeat an external effect.
- Prove it with fresh output. A claim without output is not done.
- Guard the context window: bring only the story, the checklist, and the code the task needs.
- Check the Shortcuts library before solving something from scratch.
- Remove a moving part before adding one.
